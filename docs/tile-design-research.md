# 麻雀牌SVGデザイン調査（代表牌プロトタイプ）

## 調査の扱い

外部ページは実物牌の一般的な比率・材質・意匠を確認する参考資料として閲覧した。画像ファイルのダウンロード、コピー、トレース、成果物への同梱は行っていない。最終成果物は基本図形とテキストだけで構成した独自SVGである。

## 確認できた特徴

- 市販の日本式麻雀牌は樹脂製の白〜乳白色の牌面で、縦長の標準サイズとして案内されている。Sasakiの製品情報ではMサイズを約26.7×19.7×16mmとしている。[麻雀牌「竹」製品情報](https://www.sasaki-mj.co.jp/products/detail/25)
- 実物牌・牌画像の一般的な見た目は、牌面の余白を残し、萬子・筒子・索子・字牌で異なる文字・模様を大きく配置する。牌画像の分類例では数牌・字牌・赤牌が別の画像群として扱われている。[雀のお宿・牌画像](https://suzume.hakata21.com/5zats/haiga81.html)
- 赤五は通常の5牌と区別するための赤い意匠を持つ。今回の試作では牌全体を赤くせず、牌種の模様と赤バッジを赤にした。
- 白は中央の文字を持たない表現も一般的であるため、試作では薄い内枠と小さな識別ラベルだけを置き、中央を空けた。
- 索子の1索や筒子の1筒には製品・牌画像ごとの意匠差がある。試作では特定製品を再現せず、1筒を中央円、1索を小さな鳥／葉を想起させる抽象形として表現した。

## 今回の設計判断

- 既存の80×112 viewBoxを維持し、既存の表示側との互換性を保った。
- 牌面は薄い外枠と内枠、低い濃度のインライン影で統一した。
- 萬子・字牌はフォールバック付き日本語フォントで大きく表示し、筒子・索子は円・竹・パスなどの図形を中心にしてフォント依存を抑えた。
- すべてのSVGに外部参照、スクリプト、CDN依存を持たせていない。

## 未確認事項

- 実物牌の特定メーカーごとの字体、1索の鳥意匠、白の彫刻・装飾、赤五の細部は製品差があるため、単一の正解としては扱わない。
- 日本語フォントが極端に限られる環境では、萬子・字牌の字形が変わり得る。全37種展開前に、実際のStreamlit表示環境で確認する。
