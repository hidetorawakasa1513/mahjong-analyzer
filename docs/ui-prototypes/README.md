# 卓面UIモックアップ

Phase 3-C②-Aの静的HTML/CSS試作です。NAGA参考画像から、青系の卓面、中央の局情報、四方向の河、下部の手牌、右側の操作・評価パネルという情報配置だけを参考にし、独自のHTML/CSSとして作成しています。ロゴ、キャラクター、背景画像、参考画像自体は使用していません。

## 表示

プロジェクトルートで次を実行します。

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

ブラウザで <http://127.0.0.1:8766/docs/ui-prototypes/table-mockup.html> を開いてください。`file://`で直接開いても動作しますが、HTTP経由のほうが相対パス確認に適しています。

対象幅はデスクトップの約1440〜1920pxです。1250px以下では牌を縮小するCSSメディアクエリがあります。固定サンプルのため、Streamlit、SQLite、Mortal、外部ネットワークには接続しません。

## 素材

牌画像は`../../assets/third_party/mj_king/tiles/`から相対参照しています。赤5は通常5牌から生成したプロジェクト内の派生素材です。参考画像`docs/references/naga-ui-reference.png`は第三者著作物のため`.gitignore`で除外し、Commitには含めません。

## 実データ連携時の作業

後続作業では、固定HTMLをそのまま接続するのではなく、既存の`get_review_scene()`が返す公開情報を座席相対へ変換し、河・副露・手牌・候補行動を安全な表示モデルへ渡します。相手の非公開手牌や判断後のイベントは表示しない設計を維持します。
