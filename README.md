# Mahjong Analyzer

雀魂の牌譜を活用して、自分の打牌傾向や弱点を分析するツールです。

## 目的

- Mortalを利用した打牌評価
- AI一致率・低推奨行動率・Mortal Ratingの可視化
- 対局データの蓄積
- 弱点の分析
- 過去の打牌との比較による成長の可視化

## 技術構成（予定）

- Python
- Mortal
- mjai-reviewer
- SQLite
- Streamlit

## 開発状況

現在はPhase 0（技術検証）です。

## 今後の予定

1. Mortalとmjai-reviewerの動作検証
2. 雀魂の牌譜データ取り込み
3. 打牌評価指標の実装
4. 弱点・成長分析
5. ダッシュボードの実装

## 開発方針

Mortalに実装されている機能は最大限活用し、
不足している機能だけを独自に実装します。

初期段階では、無料・ローカル環境での動作を目指します。
